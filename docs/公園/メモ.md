言語の壁はあっても、人と関わりたいという気持ちは共通です。

..."""

config からペルソナ・世界観を読み込みエージェントに渡す

self.world_context = agent_config.get('world_context', '')

エージェント生成時
persona = self.personas[i] if i < len(self.personas) else ""

    ...
    persona=persona,
    world_context=self.world_context
)

観察ポイント
□ベンチ周辺に自然と人が集まるか
□孤独型エージェント（日本/エチオピア）が話しかけられる側になるか
□積極型エージェント（アメリカ/フランス）がベンチを「許可の場」として活用するか
□多言語・多文化間での会話が発生するか
□ベンチに一度も近づかないエージェントはいるか（個人差の観察）
